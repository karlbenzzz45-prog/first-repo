How Git moves your work between four places

Working directoryFiles you edit on disk
git add
Staging areaWhat the next commit will contain
git commit
Local repositoryYour full history, on your machine
git push
Remote (GitHub)The shared copy your team sees
git pull / fetch

Each arrow moves changes one step to the right. git pull brings remote changes back to your local repository and working directory. git restore and git reset move things the other way.
